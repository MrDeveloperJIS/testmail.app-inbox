A simple inbox for your test emails

This tool reads mail straight from your testmail.app namespace and shows it in a clean, minimal inbox — no clutter, no setup beyond your own API key.

testmail.app hands out disposable email addresses under a namespace you control, so you can send test emails to a tag like yournamespace.tag@inbox.testmail.app and read them back through a JSON API. This app is a lightweight, personal front end for exactly that: sign in, generate a tag, and watch mail land in the inbox below.

  • Generate custom or auto-sequenced tags on demand
  • Search across tag and subject to find a message fast
  • Manual refresh — nothing is fetched or stored unless you ask
